# Backend

Python API and database setup will live here. The initial frontend sync test works without a backend.

Registration/login implementation will follow separately. Database credentials and authoritative game state remain server-side.

## Note:
Install [uv](https://docs.astral.sh/uv/) and use `uv pip install` should anything else need to be installed.

Use `source .venv/bin/activate` to activate the virtual enviroment for Python. 

Use `uv pip freeze > requirements.txt` if additional packages are installed.
