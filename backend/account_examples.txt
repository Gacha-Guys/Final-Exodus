-- Currency is a table with this schema:

+-------+--------------+------+-----+---------+-------+
| Field | Type         | Null | Key | Default | Extra |
+-------+--------------+------+-----+---------+-------+
| Type  | varchar(255) | NO   | PRI | NULL    |       |
| count | int          | YES  |     | 0       |       |
| u_id  | int          | NO   | PRI | NULL    |       |
+-------+--------------+------+-----+---------+-------+

-- After creating a User and inserting into the Users table, 2 entries will be added to the Currency table:
+------+-------+------+
| Type | count | u_id |
+------+-------+------+
| free |     0 |    2 |
| paid |     0 |    2 |
+------+-------+------+
-- When updating how much currency a certain user has, use this example as a guideline:

UPDATE Currency
SET count = count + 100
WHERE Type = 'free' AND u_id = 2
